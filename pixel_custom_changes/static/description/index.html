Premium Image Slider Widget for Many2many / One2many Fields

Display your image fields as a beautiful, interactive slider inspired by the native Odoo Website experience, available across all modules.

  Feature Overview

By default, Odoo displays many2many/one2many image fields as a static grid of thumbnails. With this module, you can transform those fields into a premium interactive image slider clean, smooth, and touch-friendly inspired by the image slider experience in Odoo Website.

The module provides the pixel_image_slider widget a full-featured, Pixelwave-branded slider that can be applied to any many2many/one2many image field across any Odoo model.

  •   Smooth, touch-friendly image slider on any many2many/one2many field.
  •   Works across all models: Products, CRM, Project, and more.
  •   Compatible with Odoo Studio no developer needed.

  How It Works

Apply the pixel_image_slider widget to any many2many/one2many image field via Odoo Studio (no code needed) or via an XML view override in your custom module.

  Option A Via Odoo Studio:

Open form view in Studio → click the many2many/one2many image field → set widget to pixel_image_slider → save.

  Option B Via XML Override:

Inherit the target view and add widget="pixel_image_slider" to the field. Update the module and reload slider is live.

  Note: This module provides the widget only. You must manually apply it to the desired field via Studio or XML. It does not auto-apply to any existing view.
